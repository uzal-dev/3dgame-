UZal and Sonam Choden 3D Memory Gallery

No intro/name-entry screen and no in-game editing UI. Edit all titles, story text, and the birthday wish directly in the MEMORIES array in index.html.

Add photos to the photos folder using the filenames listed in photos/README.md. The game has a left movement joystick and right camera-look joystick on mobile, keyboard movement and drag-to-look on desktop, clickable framed memories, dance, and a birthday-wish button.

See README.md for GitHub Pages setup and controls. Requires internet to load Three.js from its CDN.
